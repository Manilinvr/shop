## Ближайшие шаги

Все они — действия в чужих интерфейсах. Пошагово расписаны в
[SETUP.md](SETUP.md), из кода их выполнить нельзя.

1. **Логотип и съёмка.** Логотип — в `public/brand/`, фото загружаются в админке.
2. **GitHub Pages и домен.** Включить Pages, прописать DNS.
3. **Appwrite.** `npm run setup:appwrite`, `npm run seed:appwrite`,
   `npm run functions:build` — дальше деплой функций и переменные.
4. **Эквайер.** Договор с ЮKassa или Т-Банк, ключи в функции, тестовый платёж.
5. **Доставка.** Договор со СДЭК, ключи, проверка расчёта и ПВЗ.
6. **Telegram и почта.** `npm run telegram:register`, ключ почтового сервиса.
7. **Юристы.** Проверить оферту, политику и соглашение, внести реквизиты.

## Подготовлено к росту (ТЗ §44)

Архитектура не блокирует: несколько складов, новые способы оплаты и доставки
(через те же адаптеры), отзывы и рейтинги, бонусы и сертификаты, реферальную
программу, push-уведомления, Telegram-авторизацию, мобильное приложение
(репозитории переиспользуются).
